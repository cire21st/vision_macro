# vision_macro

화면에서 특정 이미지를 찾아 자동으로 클릭하는 간단한 파이썬 매크로입니다.
`pyautogui`의 이미지 매칭 기능을 이용해 일정 주기로 화면을 스캔하고,
지정한 이미지(`img.png`)와 일치하는 위치를 찾으면 해당 좌표를 클릭합니다.

## 동작 방식

1. `img.png`를 기준 이미지로 등록
2. 2초 간격으로 화면 전체를 스캔
3. 이미지가 발견되면 해당 영역의 중심 좌표를 계산해 클릭
4. 이미지가 없으면 아무 동작 없이 다음 스캔까지 대기

## 요구 사항

- Python 3.10+
- 패키지 설치
```bash
  pip install pyautogui
  pip install opencv-python
```

## 사용법

1. 클릭하고 싶은 대상의 스크린샷을 `img.png`로 저장해 스크립트와 같은 폴더에 둡니다.
2. 스크립트를 실행합니다.
```bash
   python vision_macro.py
```
3. 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

## 주의사항

- 디스플레이 배율(DPI Scaling)이 100%가 아니면 이미지 매칭이 실패할 수 있습니다.
- `confidence` 값(현재 0.8)은 이미지 유사도 임계값입니다. 매칭이 잘 안 되면 낮추고,
  엉뚱한 곳을 클릭하면 높여서 조정하세요.
- 멀티 모니터 환경에서는 주 모니터만 스캔될 수 있습니다.
